# 🌾 농부의시장 배치도 도우미

뚝섬한강공원 · 양천파리공원 · 화랑대철도공원을 주마다 돌아가며 열리는 **농부의시장** 농가 부스 배치도를 만드는 도구입니다.

> **팀원은 [`농부의시장_배치도.html`](./농부의시장_배치도.html) 파일 하나만 받으면 됩니다.**
> 더블클릭하면 크롬/엣지에서 열리고, 설치도 인터넷도 필요 없습니다.

---

## 1. 팀원용 사용법 (5단계)

| 단계 | 할 일 |
|---|---|
| **0. 열기** | `농부의시장_배치도.html` 더블클릭 → 처음 화면에서 행사 일정(장소별 색 구분)을 누릅니다. |
| **① 참여 명단** | 「📥 엑셀 명단 넣기」로 명단 엑셀을 넣습니다. `장소` 열이 있으면 그 장소 농가만 골라 줍니다. 토·일(·금)별 체크로 참여를 정하고, 취소는 체크 해제, 추가는 「엑셀로 추가 명단 넣기」·「농가 직접 추가」. |
| **② 칸 만들기** | 격자를 클릭/드래그해 부스 칸을 만듭니다(한 칸 = 한 농가). 격자는 기본 **20줄×30칸(600칸)** 으로 넉넉하고, 오른쪽·아래 끝까지 칠하면 자동으로 늘어납니다(「＋5줄/5칸」 버튼, 최대 100×100). 위쪽 **「남은 칸 수」가 0이 되면** 참여 농가 수와 딱 맞습니다. 장소 모양은 「기본형으로 저장」해 두면 다음 일정에서 불러옵니다. |
| **③ 농가 배치** | 「⚡ 자동 배치」→ 비슷한 품목이 붙지 않게 자동으로 놓습니다. 꼭 정해진 자리는 목록에서 농가 검색 → 클릭 → 칸 클릭하면 📌고정되고, 고정 농가는 자동 배치해도 안 움직입니다. 칸을 끌어 놓으면 자리 교체, Ctrl+Z로 되돌리기. |
| **④ 검수** | 손으로 바꾼 뒤 확인합니다. 가까이 붙은 유사 품목을 **선으로 잇고 품목마다 다른 색**으로 보여줍니다. 「🩹 문제 자리만 고치기」는 최소한만 옮겨 해결합니다. |
| **⑤ 저장·출력** | 색깔 배치도 **엑셀**, 카톡용 **그림(PNG)**, **인쇄/PDF**. |

### 다른 팀원과 나누기
상단 **「💾 공유용 파일로 저장」** → 지금까지의 일정·명단·배치도가 **들어 있는** HTML 파일이 만들어집니다. 그 파일을 카톡·메일로 보내면 받은 사람은 더블클릭만으로 같은 화면에서 이어서 작업합니다.

- 작업은 브라우저에 자동 저장되지만 **그 컴퓨터에만** 남습니다. 중요한 작업 후에는 공유용 파일로 한 번 저장해 두세요(백업 겸용).
- 여러 사람이 **동시에** 고치면 마지막에 보낸 파일만 남습니다. 한 사람씩 차례로 넘겨 주세요.
- 받은 파일을 열 때 내 컴퓨터에 이전 작업이 있으면 어느 것을 열지 물어봅니다. 받은 파일을 열어도 이전 작업은 백업되어 「⚙ 설정 → 데이터 → 직전 백업으로 되돌리기」로 꺼낼 수 있습니다.

### 일정 바꾸기
처음 화면 일정 카드의 `⋯ → 일정 수정`에서 날짜 변경, **「앞에 금요일 추가」**, 날짜 빼기가 됩니다. 새 일정은 「＋ 일정 추가」. 기본 일정(2026년 13~18회차)은 아래 표와 같습니다.

| 장소 | 13·14회차 | 15·16회차 | 17·18회차 |
|---|---|---|---|
| 양천파리공원 (노랑) | 10.3~10.4 | 10.24~10.25 | 11.14~11.15 |
| 뚝섬한강공원 (파랑) | 10.10~10.11 | 10.31~11.1 | |
| 화랑대철도공원 (분홍) | 10.17~10.18 | 11.7~11.8 | |

### 엑셀 명단 형식
첫 줄(머리글)에 아래 이름이 있으면 자동으로 알아봅니다. 순서·추가 열은 상관없고, 이름이 달라도 가져오기 창에서 열을 직접 고를 수 있습니다.

`연번 · 시도 · 시군구 · 농가명(필수) · 대표자 · 연락처 · 품목군 · 신청품목 · 신규여부 · 장소`

날짜별 참여 열(예: `토`, `10.10`, `13회차`)이 있으면 O/ㅇ/○/1/참여 값을 읽어 체크까지 해 줍니다. 연습용 파일: [`sample/예시_참여명단.xlsx`](./sample/예시_참여명단.xlsx) (가상의 농가). 앱 안의 「🧪 예시 명단으로 연습해 보기」 버튼도 같은 데이터를 넣습니다.

## 2. 유사 품목 판단과 자동 배치는 이렇게 동작합니다

### 2-1. 품목 태그
`신청품목`을 쉼표·괄호 기준으로 나누고(괄호 안 품종 설명은 무시), **품목 키워드 사전**(⚙ 설정에서 수정 가능)과 맞춰 `꿀·양봉`, `사과`, `떡`, `김치`, `젓갈·액젓` 같은 태그를 붙입니다.
- 예: `야생화꿀, 꽃가루(화분), 로얄젤리` → `꿀·양봉` (품목군이 가공식품류든 축산류든 같은 꿀로 봄)
- 오인 방지 규칙: `김치`≠`김`, `고추장`≠`고추`, `명란`≠`계란`, `로얄젤리`≠`젤리 간식` 등
- 태그가 마음에 안 들면 농가 수정 창에서 직접 고칠 수 있고, 직접 고친 태그는 사전이 바뀌어도 유지됩니다.

### 2-2. 유사도 × 거리 = 근접 위험도
```
유사도  s(a,b) = 0.35·[같은 품목군] + 0.65·[공통 품목 태그]  (최대 1)
거리    p(d)   = 1/d²   (바로 옆 1 · 대각선 0.5 · 한 칸 건너 0.25 · 반경 2.3칸 밖은 0)
근접 위험도   = s × p   →  위험 ≥ 0.6 · 주의 ≥ 0.3 · 참고 ≥ 0.15
```
| 상황 | 위험도 | 레벨 |
|---|---|---|
| 공통 품목(예: 꿀)이 바로 옆 | 0.65~1.0 | 🔴 위험 |
| 같은 품목군만 바로 옆 | 0.35 | 🟠 주의 |
| 공통 품목 + 같은 품목군이 대각선 | 0.5 | 🟠 주의 |
| 같은 품목군이 대각선 | 0.175 | 🟡 참고 |

배치 **등급(A~E)** 은 위험·주의 쌍의 수(농가 수 대비)로, **분산 점수**는 같은 농가를 무작위로 놓았을 때 대비 얼마나 덜 붙었는지(100 = 근접 없음)로 매깁니다. 가중치·반경·위아래 거리 배율(줄이 등을 맞댄 부스면 2배)은 설정에서 바꿀 수 있습니다.

### 2-3. 자동 배치 알고리즘
배치 문제는 "K개 칸에 N개 농가를 놓아 Σ 근접 위험도를 최소화"하는 **이차 할당 문제(QAP, NP-hard)** 입니다. 정확해 대신 빠른 근사 해법을 씁니다.
1. **탐욕 초기해**: 다른 농가와 겹치는 게 많은(배치가 어려운) 농가부터, 이미 놓인 농가와 충돌이 가장 적은 칸에 배치
2. **담금질 기법(Simulated Annealing)**: 임의의 두 칸 교환을 수십만 번 시도. 나빠지는 교환도 온도에 따라 확률적으로 받아들여 지역 최적해를 탈출하고, 온도를 지수적으로 낮춤. 교환 1회 비용은 두 칸의 이웃만 다시 계산(O(이웃 수))
3. **마무리 최급강하**: 개선되는 교환이 없을 때까지 모든 칸 쌍 확인
4. **재시작 3회** 중 최선 선택 · 📌고정 칸은 처음부터 제외

「문제 자리만 고치기」는 같은 최적화에 **이동 1건당 벌점(0.12)** 을 더해, 충돌을 그 이상 줄이는 이동만 일어나게 합니다(최소 변경).

실제 뚝섬 명단 47곳(가공식품류 20곳 = 43%)으로 측정한 결과 (반경 2.3칸, 47칸):

| 칸 모양 | 무작위 배치 (여러 번 측정) | 자동 배치 | 계산 시간 |
|---|---|---|---|
| 마주보는 2줄 | 등급 C~D, 위험 3~6 | **A, 위험 0·주의 0** (분산 87점) | 약 0.1초 |
| ㄷ자 / ㅁ자 | 등급 D, 위험 4~8 | **A, 위험 0·주의 0** (분산 90점) | 약 0.06초 |
| 꽉 찬 사각형 | 등급 E, 위험 10~11·주의 20~28 | **A, 위험 0·주의 2** (분산 75점) | 약 0.1초 |

꽉 찬 사각형은 상하좌우·대각선 이웃이 8곳이라, 가공식품류가 43%인 명단에서는 같은 품목군끼리 바로 옆(주의)을 완전히 없애기 어렵습니다. 줄 배치처럼 이웃이 적은 모양일수록 더 깨끗하게 흩어집니다.

## 3. 개발자용

```
farmers-market-layout/
├─ 농부의시장_배치도.html   ← 배포용 단일 파일 (빌드 결과, 팀원에게 이것만 전달)
├─ src/
│  ├─ index.html           ← 개발용 (여러 파일로 나뉜 원본)
│  ├─ css/app.css
│  ├─ js/core.js           데이터 모델·기본 일정·키워드 사전·저장/공유 파일
│  ├─ js/similarity.js     품목 태그·유사도·검수(레벨/선/등급)
│  ├─ js/optimizer.js      자동 배치 (탐욕 + 담금질 + 최급강하)
│  ├─ js/excel.js          엑셀 읽기(SheetJS)·쓰기(ExcelJS)·PNG 그리기
│  ├─ js/layout-view.js    ②칸 만들기 ③배치 ④검수 화면
│  ├─ js/app.js            일정·명단·가져오기·저장출력·설정
│  └─ lib/                 xlsx 0.18.5 (Apache-2.0), exceljs 4.4.0 (MIT)
├─ tools/build.js          src → 단일 HTML (CSS/JS/라이브러리 인라인)
├─ tests/logic.test.js     핵심 로직 테스트
└─ sample/예시_참여명단.xlsx
```

```bash
npm run build   # 농부의시장_배치도.html 다시 만들기 (src 수정 후 꼭 실행)
npm test        # 태그 추출·유사도·자동 배치·고정·공유 파일 테스트
```

- 프레임워크 없이 순수 JS(일반 `<script>`)라서 `file://` 로 더블클릭해도 동작합니다(ES 모듈·Web Worker는 file://에서 막히므로 사용하지 않음).
- 작업 데이터는 `localStorage` 에 자동 저장되고, 공유용 저장 시 `<script id="fm-embedded" type="application/json">` 자리에 JSON으로 들어갑니다.
- 실제 참여 명단(개인 연락처 포함)은 저장소에 올리지 않습니다. 예시 파일은 모두 가상의 이름·번호입니다.
